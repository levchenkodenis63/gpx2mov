# Работа с Git

После каждой завершённой доработки проверь результат. Если доработка влияет на сборку приложения, пересобери её для GitHub Pages в каталоге docs.

Добавь в индекс Git все относящиеся к задаче изменения, включая новые файлы, удаления и необходимые артефакты сборки. Проверь состав индекса и вывод git status --short --untracked-files=all, чтобы убедиться, что все файлы доработки подготовлены к коммиту.

Коммит и отправку в удалённый репозиторий выполняет пользователь.
